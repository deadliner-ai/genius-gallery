Seattle Central Library

Carol M. Highsmith, 2009

One continuous ramp across four floors, so the catalog never breaks apart.

Rem Koolhaas stacked this library like shifted boxes in a glass net. Inside, the Books Spiral is one continuous ramp across four floors, so the shelves never break the catalog apart.
