Harmony Is Arithmetic

Franchino Gaffurio, Theorica musicae (1492), -500

Halve a string and it sings an octave higher: the first hint that nature speaks math.

Halve a string and it sounds an octave higher; two thirds of it gives a fifth. The Pythagoreans found that pleasing sounds follow simple number ratios, the first hint that nature might be written in math.
