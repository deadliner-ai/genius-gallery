Your lock screen,
a gallery

A masterpiece, a photo from space or a big idea, with one line that makes you look twice. And it changes on its own.

No app needed on iPhone. Apple's Shortcuts app, already on your phone, sets the picture. Two minutes, once.

Step 1: build the shortcut

Open Shortcuts, tap +, and add these six actions in order. Search for each one by name.

Action 1
Get Contents of URL

With this address:

https://geniusgallery.app/ios/config.json
Action 2
Get Dictionary Value

Get the value for count.

count
Action 3
Random Number

Between 1 and the value from the previous action.

Action 4
Text

Paste the address, then add the Random Number variable right after it, then .jpg

https://geniusgallery.app/ios/en/
Action 5
Get Contents of URL

With the Text from the previous action.

Action 6
Set Wallpaper Photo

Choose Lock Screen, and under the small arrow turn off Show Preview and Crop to Subject.

Name it Genius Gallery and save. Tapping it already changes your lock screen, try it. If nothing happens, first pick a Photo wallpaper in Settings, then try again.

Step 2: make it automatic

In the Automation tab, tap + and pick when:

  • When you open an app you use a lot, like WhatsApp or Instagram. Next time you lock, a new work is waiting.
  • Or at set times, like morning, noon and evening.

Choose Run Immediately, then the Genius Gallery shortcut.

Want a peek first? A sample work

Each run downloads one image from our site. The shortcut collects nothing and needs no account. Apple does not allow changing the wallpaper on every unlock, so it changes when your automation runs.

On Android there is a full app that changes the work on every unlock: Genius Gallery on Google Play
