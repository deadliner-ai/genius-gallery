Jaune, rouge, bleu

Vassily Kandinsky, 1925

Le jaune fonce sur vous, le bleu recule, et le rouge garde l'équilibre.

À gauche, un jaune qui, pour Kandinsky, se précipitait vers le spectateur. À droite, un bleu profond qui s'éloigne dans le lointain. Entre les deux, le rouge garde l'équilibre. Il croyait que les couleurs bougent.
